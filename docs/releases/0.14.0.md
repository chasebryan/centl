# CENTL v0.14.0

**Version:** 0.14.0
**Platform:** GNU/Linux
**Release posture:** consolidation, hardening, and stable-baseline candidate
**Oasis status:** candidate — declaration withheld until the release gate closes

CENTL v0.14.0 is a deliberate consolidation release. The v0.13.0 development line reached a release-candidate state but was never formally published as a stable CENTL release. Rather than preserve that intermediate boundary as an artificial public release, v0.14.0 incorporates the validated work from that line together with CARAVAN and MIRAGE, then establishes a new reviewed baseline.

## Oasis declaration

**Oasis is a release classification, not a version codename.** CENTL may make an Oasis declaration whenever a release has been deliberately reconciled, organized, hardened, validated, and established as a cohesive stable baseline.

The declaration reserved for this release is:

> **CENTL v0.14.0 is an Oasis release.**

That sentence is not considered true merely because it appears in release preparation documentation. It becomes the release declaration only after the final Oasis gate is complete on the reviewed release commit. Future CENTL versions may independently receive the same classification when they satisfy the same standard.

The v0.14.0 Oasis qualification gate includes repository reconciliation, removal of obsolete release automation, documentation cleanup, security remediation, supply-chain review, clean build/test/install validation, and validation of the integrated GNU/Linux distribution.

## Included systems

### CENTL core

v0.14.0 retains CENTL's exact-first numerical contract: exact input remains exact where the admitted mathematics permits, approximations carry explicit evidence, unsupported work remains visible, and machine-facing assurance classes cannot be promoted by untrusted semantic tooling.

### CENTL-SCi v0.0.2-Caramels

Caramels remains the current scientific interaction generation, including deterministic mathematics and physics interpretation, evidence-backed presentation, persistent user workspaces, and controlled BUILD/self-extension workflows.

### CENTL-MIRAGE

v0.14.0 includes the local MIRAGE bootstrap: **Mathematical Introspective Recursive Autonomous Growth Engine**.

The v0.14.0 boundary includes:

- bounded local design-document ingestion;
- SHA-256 source identity;
- provenance-preserving Specification IR;
- typed goal and capability graphs;
- deterministic hard-requirement conflict detection;
- capability-gap analysis and existing-capability reuse;
- transaction-bound deterministic candidate materialization where supported;
- authoritative parser evidence for exact staged source;
- machine-readable evidence obligations and evidence-execution plans;
- non-mutating candidate transactions;
- explicit blocking of ambiguous, conflicting, unsupported, or policy-prohibited requests;
- local `start`, `ingest`, `analyze`, and `status` workflows.

v0.14.0 does **not** claim autonomous source mutation or autonomous promotion into verified core. Candidate material remains staged and must cross the appropriate engineering and assurance gates before activation.

### CENTL CARAVAN Phase 1

v0.14.0 includes the completed CARAVAN Phase 1 **local laboratory** for content-addressed, authenticated artifact preservation and availability.

The laboratory includes:

- immutable content-addressed storage with whole-file and deterministic chunk SHA-256 identities;
- Ed25519 pseudonymous carrier identity and proof of possession;
- signed policy-acceptance receipts;
- TUF-authenticated artifact catalog consumption;
- outbound-only laboratory carrier/coordinator transport;
- bounded transfer, session, challenge, polling, and storage behavior;
- pre-transfer capacity enforcement and authenticated chunk-size validation;
- verified multi-carrier retrieval with automatic bad-carrier quarantine/fallback;
- hostile-transfer handling for corruption, reordering, truncation, appended data, and malformed authenticated manifests;
- local join/status/leave lifecycle;
- a reproducible one-command local laboratory.

CARAVAN's governing invariant remains:

> A carrier may provide bytes, but a carrier may never define which bytes are trusted.

v0.14.0 does **not** enable arbitrary public volunteer enrollment. Production relay deployment, public enrollment, abuse operations, final telemetry/privacy policy, and other public-network rollout gates remain later work.

## Consolidation and repository hygiene

Oasis qualification treats repository state as part of release quality. Obsolete v0.13.0 one-shot tag/gate-observer automation and the obsolete fixed v0.10.0 publication workflow are removed from the active release path, stale release references are reconciled, repository structure is documented, active pull-request state is reduced to intentional work, and historical branches are classified before destructive cleanup.

Historical branches may remain as preservation refs when unique history has not been proven redundant. A branch name is not part of the supported runtime surface and its mere historical existence does not prevent an Oasis declaration.

## Security posture

Oasis qualification is gated on source remediation rather than alert suppression. Security work includes:

- immutable GitHub Action pins with accurate version annotations;
- least-privilege workflow permissions;
- dependency review;
- GitHub Actions security analysis;
- release and installer supply-chain boundaries;
- filesystem, path, symlink, and atomic-write boundaries;
- native/process/protocol resource limits;
- CARAVAN trust, identity, metadata, transfer, storage, session, and quarantine boundaries;
- MIRAGE provenance, materialization, workspace, evidence, and candidate-authority boundaries.

Security review establishes evidence for the release boundary; it is not a claim that any nontrivial software is free of all possible vulnerabilities.

## Version history note

`0.13.0` remains visible in development history and documentation where historically useful, but it is not presented as a formally published stable release. v0.14.0 is the intended public stable successor to v0.12.0.
