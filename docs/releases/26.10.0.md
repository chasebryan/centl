## Executive Summary

**CentL26.10.0** is the flagship universal multi-platform release of the Free Computation Foundation's scientific computing environment. CentL26.10 unifies exact-first computer algebra, coordinate-free relativistic physics, stoichiometric reaction balancing, dynamic STEM visualizer animations, offline academic search, and continuous Jupyter-grade notebooks into a 100% offline, deterministic scientific workbench with full native parity across **macOS**, **GNU/Linux**, and **Windows 11**.

---

## Key Highlights & Capabilities

### 1. Continuous Jupyter-Grade Notebooks & Direct `.ipynb` Export
- **Reactive Multi-Statement Cells**: Write and execute multi-line mathematical and scientific scripts in sequential computational cells.
- **Full Cell Lifecycle Controls**: Add, edit, re-run, duplicate, or delete cells with live state persistence.
- **Native Jupyter Notebook Export**: One-click export of the active session to standard Jupyter Notebook format (`.ipynb`) with complete Markdown narratives, computational inputs, and exact rational receipts.
- **Multi-Tab Workspaces**: Open and maintain independent computation workspaces in named tabs with keyboard accelerators (`⌥ W` / `⌘ ⇧ W`).

### 2. Smooth In-App Paper & Technical Manual Scrolling
- **Integrated FCF Knowledge Center**: Offline indexed document browser with responsive Markdown rendering and smooth scrolling.
- **Embedded Research Preprints**: Direct in-app reading for foundation theoretical research, including *Bryan Recursive Entanglement Calculus (BREC v1.0)*, *Erdős–Straus Modular Decomposition*, *Collatz Modular Trajectory Dynamics*, and *Ramanujan Tau Asymptotics*.
- **Comprehensive Operator Manuals**: Built-in access to CAS syntax references, exact numerical contracts, stoichiometry guides, and physics interpreter specifications.

### 3. Native Windows 11 Distribution & 1-Command Universal Installers
- **Windows 11 Native Packaging**: `desktop/centl26/windows/build.ps1` compiles and bundles standalone `CentL26-Windows-x64.zip` / `CentL26-Windows-x86_64.zip` archives with 1-click batch launcher (`CentL26.bat`), high-resolution application icon, and SHA-256 integrity checksums.
- **Universal 1-Command Setup**:
  - **macOS**: `./install.sh`
  - **Linux**: `./install.sh` or `sh install-linux.sh`
  - **Windows 11**: `.\install.ps1` or `powershell -ExecutionPolicy Bypass -File scripts\install-windows.ps1`

### 4. Robust Algebraic Engine & Canonical Polynomial Solver
- **Arbitrary-Degree Rational Root Theorem Solver**: Complete exact root extraction for linear, quadratic, cubic, quartic, and higher-degree polynomials via synthetic division (`synthetic_divide_root`) and exact radical isolation.
- **Direct Algebraic Equation Auto-Solving**: Free variable analysis automatically differentiates variable assignment (`x = 5`) from algebraic equations (`2x + 3 = 7` $\rightarrow x = 2$, `x^2 - 5x + 6 = 0` $\rightarrow x = 2, x = 3$).
- **Constant Mathematical Equality Verification**: Immediate truth-value validation (`2 + 3 = 5` $\rightarrow true$, `2 + 3 = 6` $\rightarrow false$, `2^10 = 1024` $\rightarrow true$).
- **Smart Implicit Multiplication**: Natural parsing of mathematical expressions (`2x`, `5x^2`, `3(x+1)`, `(x-1)(x+1)`, `4pi`, `2sin(x)`) while preserving plain-English natural language queries.
- **Polynomial Expansion & Canonical Factorization**:
  - `factor(x^2 - 9)` $\rightarrow (x + 3)(x - 3)$
  - `factor(x^2 - 5x + 6)` $\rightarrow (x - 2)(x - 3)$
  - `factor(x^3 - 6x^2 + 11x - 6)` $\rightarrow (x - 1)(x - 2)(x - 3)$
  - `expand((x - 1)*(x + 1))` $\rightarrow x^2 - 1$

### 5. Advanced Calculus, Discrete Mathematics & Series
- **Higher-Order Symbolic Differentiation**: `diff(f, x, n)` (e.g. `diff(x^4, x, 3)` $\rightarrow 24x$, `diff(sin(x), x, 4)` $\rightarrow \sin(x)$).
- **Definite & Indefinite Integration**: `integrate(3x^2 + 2x, x, 0, 3)` $\rightarrow 36$.
- **Symbolic Limits & L'Hôpital's Rule**: `limit((x^2 - 1)/(x - 1), x, 1)` $\rightarrow 2$.
- **Taylor Series Expansions**: `taylor(exp(x), x, 0, 3)` $\rightarrow 1 + x + \frac{1}{2}x^2 + \frac{1}{6}x^3$.
- **Discrete Summations & Products**: `sum(k^2, k, 1, 5)` $\rightarrow 55$, `product(k, k, 1, 5)` $\rightarrow 120$.

### 6. Interactive STEM Animated Visualizer & Theorem Studio
- Dynamic mathematical theorems and physics simulations rendered in real-time:
  - Fourier harmonic wave superposition
  - 2D/3D ODE wave equations and phase portraits
  - Lorenz chaotic attractors
  - Classical and relativistic particle collision kinematics
  - Bravais crystal lattice geometry and solid-state diffraction

### 7. STEM Academic Search Engine Omnibar
- Omnibar search routing to major academic registries:
  - Google Scholar
  - arXiv Preprints
  - PubMed Central
  - Wolfram MathWorld
  - OEIS (On-Line Encyclopedia of Integer Sequences)
  - NIST Chemistry WebBook
  - NASA Astrophysics Data System (ADS)

### 8. Resilient Multi-Model Gemini AI Co-Pilot
- **Intelligent Fallback Hierarchy**: `gemini-2.5-flash` $\rightarrow$ `gemini-2.0-flash` $\rightarrow$ `gemini-1.5-flash` $\rightarrow$ `gemini-1.5-pro`.
- **Persistent Key Management**: Seamless cross-platform API key configuration via `:gemini-key <key>`, environment variables (`GEMINI_API_KEY`, `CENTL_GEMINI_KEY`), or UI settings modal.
- **Decomposition & CAS Verification**: Decomposes complex STEM word problems into atomic CentL computational statements, verifying every step against the exact rational core.

### 9. Stoichiometry & Exact Reaction Balancing
- Integrated periodic table of 118 chemical elements with exact atomic weights.
- Reaction balancing via rational nullspace matrix solvers.
- Atom count verification and sample spread statistics (`spread measured`, `spread exact`).

### 10. Exhaustive 100-Test Automated Non-Regression Suite
- Complete offline test coverage across arithmetic, algebra, calculus, physics, chemistry, and project persistence.

## Verification & Integrity

All release distribution archives carry corresponding `.sha256` checksum files in `build/centl26/` and can be verified via:

```sh
# macOS / Linux
shasum -a 256 -c CentL26-macOS-arm64.zip.sha256
shasum -a 256 -c CentL26-Linux-x86_64.tar.gz.sha256

# Windows PowerShell
Get-FileHash -Algorithm SHA256 CentL26-Windows-x64.zip
```

## Upgrade Instructions

### Existing macOS App Users
CentL26 includes an integrated native updater bridge (`CentL26Updater.swift`). Click **Check for Updates** in the status bar or application menu to automatically fetch and stage the CentL26.10 snapshot.

### Git Clones & Source Builds
```sh
git fetch origin
git checkout main
cargo build --release --bin centl26
```
