## Key Highlights in CentL26.11-ES

### 1. Endless Algorithmic Hunt Studio & Visual Observatory
- **Endless Horizon Search**: Users can initiate real-time continuous Erdős–Straus searches (`es hunt [from] [window]`) advancing across search intervals with zero-scroll, zero-flashing vector animation.
- **Dynamic Multi-Engine Coordination**: Live telemetry and dynamic execution across 5 specialized mathematical kernels:
  - `CC.kernel`: O(1) linear congruences and algebraic preclearances ($4p+3$, $3p+2$, $8p+5$).
  - `CBAP.kernel`: Two-target signed box and arithmetic progression harvester (shallow corridor $\delta \le 10$).
  - `CBIS.kernel`: Trapped fiber sieve and phase contraction corridor search ($\delta \in [11, 50]$).
  - `CBX.kernel`: Lane-I profile dual descent and Kneser defect boundary ($\delta > 50$).
  - `bb.kernel`: Exact arbitrary-precision reference verification ($4xyz = n(yz + xz + xy)$ in $\mathbb{Z}$).
- **Non-Terminal Metric Accounting**: Honest dashboard telemetry tracking Primes Scanned, Mordell Radar (Hard Candidates), Theorem Clearances (CC), Corridor Clearances (CBAP), CBIS Escapes (Phase Contraction), and Verified Letters.

### 2. Central Authoritative Mathematical Letter Admission Gate
- **Authoritative Admission Predicate**:
  $$\text{is\_letter\_candidate}(p, \text{result}) = \text{is\_prime}(p) \land \text{is\_mordell\_hard}(p) \land \text{survives\_all\_preclearances}(p) \land \delta \ge \text{threshold} \land \text{exact\_verification}(p, x, y, z)$$
- **Decoupled Discovery & Admission**: Downstream search engines (`CBIS`, `CBAP`, `CBX`) no longer independently stamp arithmetic grade `LETTER`. Engines emit their structural classification (`TheoremClearance`, `CorridorHit`, `CbisEscape`, `CbxSurvivor`, `OrdinaryDecomposition`); only the centralized gate evaluates and elevates candidate solutions.
- **Strict Mordell-Hard Constraint**: Letter admission strictly fails closed unless $p \pmod{840} \in \{1, 121, 169, 289, 361, 529\}$. Non-hard residues (such as $p = 375017 \equiv 377 \pmod{840}$ and $p = 265873 \equiv 433 \pmod{840}$) are classified as CBIS Escapes or Corridor Clearances, never admitted into the genuine letter ledger.

### 3. Isolated Dual Vault System & Historical Migration Suite
- **`letters/` Genuine Letter Vault**: Persists admitted letters as structured Markdown (`L-<p>.md`) and JSON (`L-<p>.json`) with cryptographic `ES-LETTER-v1` SHA-256 certificates and full mathematical provenance.
- **`escapes/` Corridor Escape Vault**: Preserves non-letter corridor discoveries as `ESC-<p>.md` and `.json` with explicit rejection rationale and exact 3-fraction identities.
- **Historical Vault Migration Engine (`audit_and_migrate_vault`)**:
  - Non-destructive re-audit command (`:es audit` / `:es migrate` / `/api/es/audit`).
  - Verifies legacy records against current mathematical criteria and relocates non-letters to `escapes/` without deleting historical discoveries.

### 4. High-Performance Overflow-Free Arithmetic
- Upgraded intermediate polynomial and signed box calculations ($n \times x$, $den \times y$) to `u128` arithmetic, eliminating integer overflow across deep coordinate horizons ($> 4.1 \times 10^{20}$).

### 5. Examination Lens & Ledger UI
- **Pinned Candidate Inspector**: Full mathematical examination card detailing Prime $p$, Residue mod 840, Discovering Engine, Search Depth $\delta$, Admission Status (`ADMITTED` vs `REJECTED`), Rejection Rationale, Exact Rational Proof, SHA-256 Certificate, and Vault Location.
- **Scroll-Contained Discovery Ledger**: Dynamic ledger table with distinct visual badges for Letters (gold), CBIS Escapes (cyan), and Corridor Hits (blue).
- **One-Click Export**: Dedicated JSON exporter for genuine letters (`/download/letters.json`) and corridor escapes (`/download/escapes.json`).
