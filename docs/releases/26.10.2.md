# CentL26.10.2 — Official Release Notes

**Release**: `CentL26.10.2`  
**Date**: `2026-08-22`  
**Codename**: `CentL26 Scientific Notebook & LaTeX Typography Standard`  
**Distribution Matrix**: macOS (Apple Silicon / Intel), Windows 11 (x86_64), Linux (Debian / Fedora / Arch)

---

## Executive Summary

**CentL26.10.2** introduces Jupyter-grade interactive notebook workflows, a native offline LaTeX mathematical typography engine, the definitive 13-domain FCF Operator Manual, and macOS WKWebView lockout prevention with safe client-side Blob downloads.

---

## Key Highlights in CentL26.10.2

### 1. Jupyter-Grade Interactive Notebook Workflows & UI
- **Cell Gutter Architecture**: Structured `In [n]:` and `Out [n]:` prompt gutters with execution microsecond timing ($\mu\text{s}$) and exact interval enclosure badges.
- **Per-Cell Action Controls**: Each cell features instant actions: `▶ Run` (re-execute), `+ Above` (insert code cell above), `+ Below` (insert code cell below), `▲` / `▼` (reorder cells), `✏ Edit` (edit in composer), `📋 Copy` (copy expression), and `✕ Delete` (remove cell).
- **Workspace Toolbar Actions**: Added clean developer controls: `Code` (`</>`), `Markdown` (`M↓`), `▶ Run All` (evaluate whole notebook), `↺ Restart` (`rotate-ccw`), `Visualizer`, `Tools` (`⌘P`), `Save` (`⌘S`), `Settings`, `Help`, and `Theme`.
- **Keyboard Shortcuts & Command Mode**:
  - `Shift + Enter`: Execute active command and advance focus.
  - `Ctrl + Enter` / `⌘ Enter`: Execute active command in place.
  - `Alt + Enter`: Execute active command and insert a blank cell below.
  - Command Mode (`Esc`): `A` (add above), `B` (add below), `M` (markdown note), `Y` (code cell), `K` / `Up` (navigate up), `J` / `Down` (navigate down), `Enter` (edit focused cell).

### 2. Self-Contained LaTeX & Mathematical Typography Engine
- **Native Math Parser (`renderLatexMath`)**: Zero-dependency client-side LaTeX parser that accurately formats:
  - **Fractions & Roots**: Nested `\frac{a}{b}`, `\sqrt{x}`, `\sqrt[n]{x}`, and binomial coefficients `\binom{n}{k}`.
  - **Greek Alphabet & Constants**: `\alpha` through `\omega`, `\Delta`, `\Gamma`, `\Theta`, `\Sigma`, `\Phi`, `\Psi`, `\Omega`, `\pi`, `\hbar`, `\ell`.
  - **Blackboard Bold Sets**: `\mathbb{Q}`, `\mathbb{Z}`, `\mathbb{R}`, `\mathbb{N}`, `\mathbb{C}`.
  - **Arrows & Operators**: `\rightarrow`, `\leftarrow`, `\Rightarrow`, `\implies`, `\to`, `\mapsto`, `\approx`, `\le`, `\ge`, `\neq`, `\pm`, `\times`, `\cdot`, `\in`, `\notin`, `\subset`, `\cup`, `\cap`, `\equiv`.
  - **Calculus & Big Operators**: `\sum`, `\prod`, `\int`, `\iint`, `\oint`, `\partial`, `\nabla`, `\pmod{m}`, `\lim`.
  - **Display Math Blocks**: Centers and styles display formulas `$$...$$` with stacked fraction numerators and denominators.
- **Pre-Extraction Syntax Protection**: Math formulas are extracted prior to markdown italic/bold parsing, preventing arithmetic asterisks from accidentally corrupting mathematical symbols.
- **Automatic Hydration**: Automatically renders math and LaTeX across both the in-app documentation viewer and notebook markdown cells (`.markdown-rendered-body`).

### 3. Definitive CentL26 Operator Manual
- **13 Comprehensive Domains**: Authored the canonical Operator Manual in `src-web/server/fcf_docs.rs` covering:
  1. Philosophical Grounding & Exact-First Architecture
  2. Interactive Notebook Workspace & Multi-Tabs
  3. Workspace Toolbar & Controls
  4. Keyboard Shortcuts & Command Mode
  5. Exact Mathematical Engine & CAS Syntax
  6. Physics & SI Mechanics Engine
  7. Chemistry & Stoichiometry Engine
  8. Research Kernels & Number Theory
  9. Interactive STEM Animated Visualizer & Theorem Studio
  10. In-App Programmability & Extensions (`build`)
  11. AI Co-Pilot (Gemini Command Integration)
  12. Project Storage, Exports & Interoperability
  13. Master System Commands Reference Table
- **Structured Offline Reader**: Enhanced the in-app document reader with responsive Markdown table support (`.fcf-doc-table`), horizontal dividers, and ordered lists.

### 4. macOS WKWebView Lockout Prevention
- Replaced direct `<a href="/download/...">` toolbar links with safe client-side Blob downloads (`URL.createObjectURL(blob)`), ensuring notebook exports (`.ipynb`, `.md`, `.json`) trigger standard macOS save dialogues without navigating WKWebView away from the app.

### 5. Clean Vector Search Symbols & Aesthetics
- Removed legacy Chrome emblems and emojis from the search omnibar and dropdown results, replacing them with crisp line-art SVG vector symbols.
- Refined the Restart icon with a geometrically accurate counter-clockwise circular reload arrow.

### 6. Preferences & Settings Protection
- Disabled the "Start Fresh Computation" option in Preferences & Settings and marked it with an explicit **Unavailable** badge.
- Enforced **Resume Previous Session** as the permanent default behavior to protect active user calculations.
