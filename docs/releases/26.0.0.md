# CentL26 26.0.0 — Flagship Main Release

CentL26 is the new flagship product direction of the Free Computation
Foundation: a standalone, offline scientific IDE for getting real work done.

## Highlights

- Frozen, enforceable modern IDE visual system with FCF / Free Computation Foundation identity.
- Native macOS application shell with an embedded loopback-only CentL26 backend.
- Durable, atomic project notebooks that restore across restarts.
- Exact-first mathematics, physics, Erdős–Straus research, and authoritative chemistry operations.
- Machine-preserved evidence for chemistry, physics, and research results.
- Authenticated local mutations, safe state roots, process locking, bounded providers, and immutable packaging.
- Design-contract and regression gates that prevent accidental visual drift.

The local macOS package is intentionally labeled **local-unqualified** when
built with ad-hoc signing or a non-pinned native toolchain. Official public
qualification requires the pinned native toolchain, a clean immutable commit,
Developer ID signing, and notarization.

CentL26 is the 2026 product train. Future feature releases use `CentL26.1`,
`CentL26.2`, and so on; maintenance releases use the corresponding patch
version.
