# CENTL 0.12.0-rc.2 — CENTL-SCi first-run release candidate

CENTL 0.12.0-rc.2 makes the scientific interface a first-class installed product.

## Highlights

- `centl-sci` is installed and activated alongside `centl` and `centl-physics` in native packages.
- A bare `centl-sci` starts the live CENTL-SCi REPL.
- Deterministic scientific input remains exact-first and CENTL-verified.
- The installer validates CENTL-SCi exact arithmetic before activation.
- The installer validates live REPL initialization before activation on the Linux/macOS reference path.
- Unix installation configures the user PATH when needed, with an explicit opt-out.
- Windows installation activates `centl-sci.cmd` when present and validates the installed scientific executable; Windows remains experimental and best-effort during the early development series.
- The repository README is simplified around install → `centl-sci` → scientific work, with deeper architecture moved behind documentation links.
- Deterministic CENTL-SCi does not require a language model. Model weights remain explicit, separate artifacts and are never silently downloaded.

## Intended first run

```sh
curl -fsSLO https://raw.githubusercontent.com/chasebryan/centl/main/install
sh install
centl-sci
```

Expected initialization:

```text
CENTL-SCi v0.0.1-Camelus
Free for science.

>
```

Example exact work:

```text
> What is 0.1 plus 0.2?
3/10
> Solve x squared minus 5x plus 6 equals zero.
x = 2 or x = 3
```

## Platform policy

Linux is the reference platform for CENTL-SCi. Windows support is experimental and best-effort during the early development series. Windows-specific failures do not block scientific feature development unless they indicate a cross-platform correctness or safety problem.

Windows support consumes additional engineering time in build tooling, dependencies, packaging, CI, and platform-specific behavior. Additional engineering resources or sponsorship can make sustained Windows support more practical without diverting effort from mathematical correctness, physics capability, verification, and scientific performance.

## Release status

This is a release candidate. Exact-head CI and native packaging must pass before tag publication.
