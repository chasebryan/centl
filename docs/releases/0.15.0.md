## Oasis declaration

> **CENTL v0.15.0 is an Oasis release.**

This Oasis is named **Al-Nur**. The name is the desert name. It is not
the tag.

This text is carried in the candidate so the declaration and the source
are tested together. It becomes authoritative only if this exact SHA
passes every applicable local and hosted Oasis gate, is fast-forwarded
unchanged to `oasis`, receives the exact `v0.15.0` tag, and publishes
the already-qualified bytes. Any later source edit is a new candidate.

CENTL v0.14.0 remains the last completed Oasis until that chain closes.

## Native release boundary

The standard native archive is GNU/Linux x86_64 and installs:

- `centl`
- `centl-physics`
- `centl-sci`

MIRAGE, CARAVAN, FCF Camps, and CENTL Marsa stay outside the installed
product. Their source may be present. Presence is not Oasis assurance.

## Source

This identity is the official snapshot of the current `main` tree.
`mirage` has the same tree. The commit parent is the current `oasis`
tip so Oasis does not regress. After this snapshot is promoted,
development continues on `mirage` and `main`.

`./scripts/oasis --snapshot` reports that procedure. It cannot declare
Oasis.
