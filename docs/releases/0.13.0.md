# CENTL 0.13.0 — Caramels

CENTL 0.13.0 is the stable Linux-first release centered on **CENTL-SCi v0.0.2-Caramels** and the Free Computation Foundation preservation/recovery work completed after 0.12.0.

## Highlights

- CENTL-SCi v0.0.2-Caramels answer-first scientific interaction
- `MATH>`, `PHYS>`, `HYBRID>`, and `BUILD>` interaction modes
- deterministic natural-language fast paths for supported mathematics and physics
- evidence-backed results, clarification, structured recall, and assurance explanations
- user-owned workspaces, revisions, snapshots, package composition, import/export, validation, and audit
- dependency-aware local extension lifecycle and controlled BUILD planning
- closed verification claims and supported uniform-gravity mechanics through typed CENTL/CENTL Physics lowering
- optional local semantic-model interpretation kept behind the CENTL trust boundary
- GNU/Linux as the sole active development, validation, packaging, installation, and release target
- FCF-controlled preservation of release bytes and recovery-critical project material
- local preservation drills and checkout-independent offline recovery tooling
- preserved CENTL-SCi runtime/model provenance and immutable base-model repository revisions
- host-neutral static release roots for FCF or other HTTPS/file-backed mirrors
- verified public-only release export that does not leak private preservation material

## Release boundary

CENTL CARAVAN is **not included in v0.13.0**. Its architecture and Phase 1 laboratory implementation remain a separate future release line.

The experimental external JSONL execution boundary is also not part of the v0.13.0 stable contract and remains under development.

macOS and Windows are not active support targets for this release. Historical code may remain available, but current release engineering is GNU/Linux-focused.

## Trust boundary

CENTL continues to follow the same numerical rule: never manufacture mathematical certainty. Generated, model-produced, or external semantics do not promote themselves to verified CENTL core. Exact values remain exact where admitted; approximations and unsupported work remain explicit.
