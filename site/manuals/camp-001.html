Title: FCF Camp #1 — Laboratory waystation

A Camp is a stay. This release is the snapshot of that stay.

What this release is

This is the first named FCF Camp artifact. It collects everything this expedition can honestly call stayable: the published Oasis product people should still install, plus the inspect, documentation, discovery, and laboratory surfaces that occupy CAMP-001.

It is not an Oasis qualification. It does not run scripts/oasis.py --final. It does not move oasis. It does not replace the v0.14.0 tag.

Install the stable calculator from the Oasis identity:

curl -fsSLO https://raw.githubusercontent.com/chasebryan/centl/oasis/install
sh install
centl-sci

Use this camp tag only when you want the stay snapshot (source, docs, site, inspect commands, proposal).

Stable product (inherited, not re-declared)

These are the Oasis-qualified public commands. They remain CENTL v0.14.0:

SurfaceStatus
centlexact calculator, JSON, MCP
centl-physicstyped exact-first physics
centl-scilocal scientific interpreter; not a general chatbot

Also stable as documentation and policy, not as a new product version:

  • numerical contract, protocol, and MCP adapter
  • Apache-2.0 use, DCO contributions to mirage
  • company and AI-software proposal
  • public sponsorship routes
  • static FCF site (visual design unchanged)

Stayable camp surfaces (not Oasis)

These are occupied with CAMP-001. They are real and inspectable. They do not inherit Oasis assurance:

  • centl-mirage oasis, wellspring, and camps (inspect only)
  • centl caravan inspect and CARAVAN Phase 1 laboratory coverage
  • SCi English workshop and reviewed publish (laboratory)
  • MIRAGE local cycles that cannot activate source by themselves
  • site discovery (llms.txt, ai.html, proposal)
  • workflow token hygiene on this line

Not included as stable

  • a new SemVer or Oasis declaration
  • Wellspring designation
  • public volunteer CARAVAN as a production network
  • verified-core rewrite by SCi or a model
  • changes to the signed join-caravan cryptographic scheme
  • JavaScript on the public site
  • a rebuilt native archive pretending to be v0.14.0

The signed join installer remains fcf-caravan-join-1.0.8. This camp does not replace it.
