Release: CentL26.13-AG (v26.13.0)

Date: 2026-08-23

Executive Summary

CentL26.13-AG is an agnostic proof ⊕ disproof machine for Erdős–Straus. Class theorems cover 7/8 of the primes. Instance witnesses do not prove the conjecture. A certified empty complete region would disprove it. Approximates never certify. Game status is OPEN.

  • Dual ledger HUD: proof / disproof / weighing.
  • Two-target k identities and divisor-complete search for n ≤ 10^4.
  • God's Letters are incomplete residuals, not disproofs.
