Oasis declaration

CENTL v0.15.0 is an Oasis release.

This Oasis is named Al-Nur. The name is the desert name. It is not the tag. The GitHub release title is CENTL v0.15.0-Oasis.Al-Nur.

The exact source is d9bcc5122d1f8e7a673f02d741c77e8145717695 on oasis, tagged v0.15.0. After this snapshot, development continues on mirage and main. A later Oasis needs a new SemVer identity.

Native release boundary

The standard native archive is GNU/Linux x86_64 and installs:

  • centl
  • centl-physics
  • centl-sci

MIRAGE, CARAVAN, FCF Camps, and CENTL Marsa stay outside the installed product. Their source may be present. Presence is not Oasis assurance.
