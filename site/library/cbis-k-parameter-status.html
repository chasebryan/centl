ES+ / kernel audit

K is a static operator parameter in cbis.kernel 1.2.0, but it is not the complete finite search grade and it is not the observed operational frontier.

Source subnote in the repository · CB X-ray Kernel

Status: research subnote / implementation plan

Date: 2026-08-15

Kernel audited: cbis.kernel 1.2.0

Successor research instrument: cbx.kernel — CB X-ray Kernel

Claim boundary: this work does not prove Erdős–Straus, does not prove that the ES+ letter spectrum is empty, and does not supply a theorem-backed universal finite K.

1. Executive finding

cbis.kernel 1.2.0 is an operational letter engine with two walks and one stacked cover:

\text{hard prime}\to W\to I\to N\to L\to\text{LETTER}.

The sweep walks hard primes. The home walk targets the residual

R=\{p:p+4\in\Sigma_1,\ 4p+1\in\Sigma_1\},

which is exactly where the two linear W clauses miss. Version 1.2.0 leaves the 1.1.0 hunt mathematics intact and chiefly adds the live panel.

The central audit result is that the scalar K displayed by cbis is not the complete finite search grade. At the ranges already observed, it is also not the main gate. W/fab is.

2. What K actually controls

The default is DEFAULT_KMAX = 400, overridable by --k-max. No internal algorithm adapts it to p, the spectrum, the defect, or the frontier.

Lane I

in_signed_box_cover(p,K) checks the admissible shifts

k\equiv3\pmod4,\qquad 3\le k\le K,

forms C=(p+k)/4, and evaluates the signed-box Type-I/II vacancy test. Here K is a shift bound.

Lane L

in_lopez_cover(p,K) instead treats the loop variable as a López layer index a. The associated prime modulus is

m=4a-1.

At K = 400, Lane L can therefore inspect prime moduli through 1599. The same scalar has a different mathematical role.

Lane N

Lane N does not use K as its ceiling. It is controlled by NR_ELL_MAX = 300 and may deliberately realize shifts larger than K.

W/fab

W is likewise outside K: the two linear identities plus the fixed coprime fab(a,b) menu with a,b ≤ 11.

3. The complete finite grade

A run is more faithfully described by

\boxed{\Gamma=(F,K_I,E_N,A_L)}

with the current default geometry

\boxed{\Gamma=(11,400,300,400).}
CoordinateMeaning
Ffab edge, currently a,b ≤ 11
KILane-I signed-box shift bound
ENLane-N external nonresidue-prime bound
ALLane-L López layer bound

A reproducible experiment should additionally carry kernel version and any named adaptive rule. The production cbis implementation happens to tie K_I=A_L=K; theory does not require that coupling.

4. Why K is presently behind W

Finite census through 108 found that roughly 27% of hard primes reach R after both linear clauses miss, but every observed member of R is subsequently hit by the fixed fab menu. Larger runs have shown the same qualitative pattern.

Because cbis evaluates W first, I/N/L do not see those targets. Raising K does not change the verdict while W continues closing the residual first.

Do not weaken W. Look through it.

Every W clause is a genuine construction. The useful experiment is to retain the ordinary verdict while evaluating I/N/L anyway.

5. Implementation findings in cbis.kernel 1.2.0

solve is fixed at the default K

The running hunt stores seed.kmax, but cmd_solve() calls in_cover_forward(n, DEFAULT_KMAX). A hunt at K = 800 can therefore coexist with a one-shot solve answer evaluated at K = 400.

ES-LETTER-v1 identifies the event, not the finite grade

The identity hash is based on the rule and prime, not K or the complete grade. That is useful if the ID names the mathematical event, but the finite certificate must be attached separately.

Changing K can mix a corpus

A pre-existing seed can be continued at another K without rewinding earlier work. Existing content-addressed letter files are not rewritten. Without explicit grade metadata, one directory can silently contain observations made at different finite strengths.

Sweep and home may observe the same target

The file identity prevents duplicate letter files, but accounting must distinguish observations from unique letters.

Home has an endpoint-repeat convention

The 1.2.0 home cursor stores the last S rather than the strict next S, so a batch endpoint can be revisited. The successor uses a strict next-cursor convention.

Factorization has a future exactness boundary

The current bounded trial-factor table is practical at today’s range, but an indefinitely growing kernel needs a general exact 64-bit factorizer. CBX therefore uses deterministic 64-bit Miller–Rabin plus Pollard rho.

6. The theoretical inversion is still available

The ES+ letter equation gives a genuinely inverse generation scheme:

k\to C\text{ with }\delta_k(C)=0\to p=4C-k.

Current cbis Lane I instead recognizes membership starting from p:

p\to k\to C.

That is not a correctness error. It means the generator-oriented inversion remains an additional algorithmic weapon beyond the present recognition engine.

7. CB X-ray Kernel

cbx.kernel is a separate research instrument. It keeps the production verdict W → I → N → L, but evaluates the lanes independently so W cannot hide the later geometry.

For Lane I it records the first signed-box depth

\boxed{k_I^*(p)=\min\{k\equiv3\pmod4:\delta_k((p+k)/4)=0\}.}

For Lane L it records the first López layer a_L*(p). For N it records the first external nonresidue prime and realized shift. For W it records linear status, R, and the first deterministic fab pair.

Observations are tagged by spectrum A/B/C and include basic factor data at the first I hit: distinct factor count, total valuation count, and signed-box size.

First exposed X-ray example

The known prime 2521 is in R and production W finishes it by fab. CBX nevertheless looks underneath that verdict. At the default grade it reports:

W: linear=false, R=true, fab=(2,1)
I: hit=true, first_k=23, omega=3, Omega=4, box_size=45
N: hit=true, ell=11, shift=31
L: no hit through A_L=400
production_letter=false

This is exactly the kind of buried depth information that ordinary cbis never needs to expose.

8. Adaptive K is experimental, not theorem-backed

No current theorem supplies a universal function K(p). CBX therefore keeps fixed K as the default and exposes named research policies only for measurement:

K(p)=\lceil c\log p\rceil,
K(p)=\lceil c(\log p)^2\rceil,

plus a spectrum-weighted logarithmic policy. Every observation records the policy name, scale, configured ceiling, and realized Lane-I bound. These policies are heuristics until proved.

9. Empirical-to-theorem workflow

  1. Measure: run I/N/L through primes already killed by W.
  2. Stratify: compare A/B/C, R/non-R, fab-only/linear, factor structure, and defect signatures.
  3. Fit an envelope: search for a low-growth upper envelope for first-hit depth.
  4. Prove or break it: use signed-box, Kneser-defect, reciprocity, and spectrum theory.
  5. Promote only after proof: theorem-backed rules may later become production grades.

10. Preservation and compatibility

  • cbis.kernel 1.2.0 remains the production letter engine.
  • cbx.kernel has separate state, observations, and named immutable grades.
  • X-ray observations are not ES letters.
  • A genuine stacked miss preserves the existing ES-LETTER-v1 identity, with exact grades written separately.
  • Sweep and R-home use separate cursors; CBX home stores the strict next S.
  • Adaptive policies are explicitly marked experimental.

11. Implementation surface

make -C research/erdos-straus/cbx.kernel
./centl es cbx self-test
./centl es cbx probe 2521
./centl es cbx go
./centl es cbx go --run deep-I --i-max 2000
./centl es cbx go --run adaptive-a --i-max 5000 --k-policy log2 --policy-scale 2.0
./centl es cbx go --home-only
./centl es cbx status --run deep-I

The current implementation includes deterministic 64-bit primality, Pollard-rho factorization, W/R/fab instrumentation, independent I/N/L depth searches, production-equivalent verdicts, immutable named grade vectors, experimental adaptive-I policies, JSONL observations, separate sweep/home state, deduplicated per-run letter accounting, and ES-LETTER-v1 compatibility.

12. Research priority

The immediate priority is not to increase K blindly. It is to expose the data that W currently hides:

\boxed{\text{measure }k_I^*(p),\ a_L^*(p),\text{ and N-depth even when W already wins.}}

If a low-growth envelope exists, the surrounding defect and spectrum theory can attack it. If no stable envelope exists, that negative result is equally useful.

\boxed{W/\mathrm{fab}\text{ is the observed operational frontier; K is a research coordinate, not the frontier itself.}}

Erdős–Straus remains open. A finite LETTER is not a counterexample, and a finite empty letter spectrum is not a proof.
