Implementation note

CBX is a separate X-ray research kernel: same mathematical finite cover order, independent hidden-lane measurement, stronger preservation semantics.

Canonical source note in the repository

Status: active experimental research kernel implementation

Production boundary: cbis.kernel 1.2.0 remains the production letter engine.

Claim boundary: this page records software and finite-search semantics. It does not establish an adaptive K law and does not prove Erdős–Straus.

Separate job, separate state

cbis.kernel asks whether the production cover disposes of a hard prime. cbx.kernel asks what every lane would have done independently, even when W already solved the target. The production order remains W → I → N → L; CBX merely X-rays underneath it.

Finite grade

\Gamma=(F,K_I,E_N,A_L)

The default grade is (11,400,300,400). Named run grades are immutable. A different finite strength requires another run name.

Crash preservation

  • An entered target finishes all lane measurements before SIGINT/SIGTERM is honored.
  • Sweep resumes after the last fully processed integer; home resumes at the first unprocessed S.
  • A hard crash may replay an uncheckpointed batch, but it does not skip it.
  • A crash-truncated final JSON append is trimmed on restart; the analyzer also tolerates only that incomplete EOF case.
  • One writer owns a named run at a time. The POSIX lock is released automatically if the process dies.
  • Unique-letter counts are reconciled from durable per-run markers.

Exactness boundary

At the same finite grade CBX uses the same mathematical W/I/N/L predicates and ordering as cbis. CBX intentionally does not reproduce cbis’s eventual bounded-factorization failure mode: it uses deterministic 64-bit Miller–Rabin and Pollard-rho factorization. Its external-NR Jacobi path is also unsigned-64-safe.

Adaptive-K research loop

The analyzer tracks the observed first-depth frontier and can directly falsify candidate rules such as K(p)=ceil(c log p) or K(p)=ceil(c (log p)^2).

It also computes the conservative finite calibration

c_{obs}=\max_{p\ observed} k_I^*(p)/B(p)

for all targets and separately inside R, together with the exact prime forcing each maximum. These are finite calibration statistics only.

First clean census

The deterministic default-grade census reached a sweep cursor of 234,540,000, recorded 401,752 Mordell-hard-prime X-rays and produced zero production letters. The finite observed Lane-I record was 107 at p=8,803,369; inside R the Lane-I p99 was 27.

The deliberately aggressive rule K(p)=ceil(2 log p) already fails 244 of 102,502 measured R targets in that corpus.

Regression gate

A dedicated GitHub Actions workflow builds and exercises CBX on Linux and macOS, including the root launcher, the known 2521 X-ray, a deterministic finite census, analyzer parsing and immutable-grade rejection.

Next targets

  1. Accumulate deeper fixed-K corpora, especially inside R.
  2. Archive publication-grade raw streams outside git with checksums.
  3. Correlate new first-depth records with factor structure, box size, spectrum, defects and López depth.
  4. Keep trying to break candidate K envelopes before attempting a theorem.
  5. Investigate the still-unimplemented true inverse orientation k → C → p.

Erdős–Straus remains open. CBX is an X-ray instrument, not a proof engine.
