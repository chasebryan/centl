Research library · Erdős–Straus · ES+

Implementation note

CBX is the separate ES+ research kernel for hidden-lane measurement, finite-cover traversal experiments and adaptive-K falsification. cbis.kernel remains the production ES-LETTER engine.

Canonical repository note

Primary platform: Fedora-family GNU/Linux. Ubuntu is a secondary Linux check.

Production boundary: cbis.kernel 1.2.0 remains untouched as the production letter hunt.

Claim boundary: finite software equivalence, operation counts and measurements are not an adaptive-K theorem and are not a proof of Erdős–Straus.

The finite grade

\Gamma=(F,K_I,E_N,A_L)

Default: (11,400,300,400). Named X-ray runs have immutable grades, preventing silent mixed-strength corpora.

X-ray runtime

CBX measures I/N/L even when W already solves the prime, without changing the ordinary W → I → N → L production verdict. The runtime uses deterministic 64-bit Miller–Rabin, Pollard-rho factorization, target-atomic signals, crash-tail repair, replay-over-skip recovery, per-run writer locks and exact finite-grade serialization.

Three exact Lane-I traversals

p-major recognition

p\to k\to C=(p+k)/4

C-major construction

k\to C\to p=4C-k

shift-major survivor traversal

k\to p\to C=(p+k)/4

Both non-reference engines support target-by-target verification against p-major, including equality of the minimal first shift k_I*(p).

What the Fedora benchmark found

On the finite corpus p ≤ 100,000, K_I=80:

  • strict C-major factorization ratio: 20.198020× p-major;
  • target-gated C-major factorization ratio: 1.000000×;
  • shift-major factorization ratio: 1.000000×;
  • shift-major active-visit ratio: 1.000000×.

The canonical shift-major wall ratio was 0.992221×; later CI landed just above one. The result is treated as practical parity, not a timing theorem. Read the full benchmark.

Per-shift telemetry

cbx inverse --layers FILE records compatible C count, hard-target encounters, target/covered/coprime skips, actual factorizations, vacancy hits and genuinely new coverage for each k. cbx analyze-layers ranks marginal yield and flags layers that spend factorization work while adding no new targets.

On the small Fedora smoke corpus, 20 shifts through k=79 were represented. Only 3,7,11,15,19,23,27,31 were productive, but no layer performed factorization work while adding zero coverage. The remaining shifts did no expensive work because the frontier was already empty. That is evidence against casual heuristic pruning.

Adaptive-K research

The clean X-ray census through sweep cursor 234,540,000 recorded 401,752 hard-prime X-rays and zero production letters. The finite Lane-I record was k*=107 at p=8,803,369. Inside R, p99 was 27. The candidate K(p)=ceil(2 log p) fails 244 of 102,502 measured R targets.

CBX therefore treats candidate K laws as things to falsify, not things to promote from a good fit.

Fedora-first validation

The mandatory workflow runs on Fedora-family GNU/Linux first and Ubuntu second. It checks X-ray semantics, immutable grades, all three Lane-I traversals, exact equivalence, per-k telemetry and orientation benchmarks.

A separate parameterized Fedora research workflow performs deeper censuses without making every ordinary PR pay for them. It preserves exact hit/residual sets, per-k telemetry, benchmarks, environment provenance and SHA-256 manifests as Actions artifacts.

macOS and Windows do not drive CBX. Compatibility there is only a natural byproduct if it happens.

Current frontier

The engineering hypothesis is now a hybrid Lane-I scheduler: generated shifts where construction is economical, shift-major traversal where the frontier structure helps, and recognition fallback elsewhere. The scheduler must be driven by larger exact per-k censuses and then challenged by the existing defect/spectrum theory before any mathematical conclusion is claimed.

Erdős–Straus remains open. CBX is an exact finite research instrument, not a proof engine.
