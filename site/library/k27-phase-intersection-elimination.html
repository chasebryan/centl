Claim boundary: exact necessary mode intersections and contradictions inside the k27 survivor grammar. This is not a termination theorem, not a closed decomposition method, and not an Erdős–Straus proof.

1. Phase selectors are set-valued constraints

The landed feedback theorem gives

tau13=8   -> {Q,E}
tau17=6   -> {B,D}
tau19=8   -> {Q}
tau31=7   -> {Q,A,D}
tau43=27  -> {Q}.

All constrain the same exact k27 NR-skeleton coordinate. Simultaneous phases therefore require mode-set intersection. Empty intersection is an exact contradiction with k27 survival; singleton intersection is a mode selector.

3. Exact contradiction progressions

Three pairwise collisions have empty k27 mode intersection:

t=125 mod221  : tau13=8 + tau17=6
t=312 mod323  : tau17=6 + tau19=8
t=414 mod731  : tau17=6 + tau43=27.

They are periodic k27 absorption classes generated by incompatible forced factor geometry, not by a single one-factor killer.

4. Unique non-Q selector

The phase pair

tau17=6
tau31=7

has exact CRT class

t=193 mod527.

Its mode requirements are

{B,D} intersection {Q,A,D} = {D}.

Therefore

t=193 mod527 AND k27 miss -> k27_NR_mode=D.

This is the first pure CRT-phase combination in the present grammar that selects a unique non-Q k27 mode.

5. Route-B consequences

Route-B k19 BARE forces tau19=8. Since tau17=6 is incompatible with that phase at k27,

Route-B k19 BARE + tau17=6 -> k27 hit.

Writing Route B as

t=705+1081u,

we have

tau17=6 -> u=10 mod17
BARE     -> u=16 mod19

and the excluded joint class is

u=282 mod323.

For the non-Q selector pair,

tau17=6
tau31=7

we have

t=193 mod527
u=469 mod527.

If the Route-B branch survives k19, k27, and k31, then

  • k27 is D by the phase intersection;
  • k31 is FULL_QR because tau31=7 is outside the BARE phase set {0,19,29};
  • k19 is FULL_QR because BARE would force tau19=8, contradicting tau17=6 at k27.

Hence

Route B + tau17=6 + tau31=7 + survival
  -> k19 FULL_QR
  -> k27 D
  -> k31 FULL_QR.

6. Constraint-engine consequence

The propagator should intersect phase-induced k27 domains before factor enumeration:

K27_ALLOWED = {Q,A,B,C,D,E,F}
if tau13==8:  K27_ALLOWED &= {Q,E}
if tau17==6:  K27_ALLOWED &= {B,D}
if tau19==8:  K27_ALLOWED &= {Q}
if tau31==7:  K27_ALLOWED &= {Q,A,D}
if tau43==27: K27_ALLOWED &= {Q}

An empty set is contradiction in the exact survivor grammar. A singleton is a forced local mode.

7. Bryan Entanglement Cross / BREC boundary

An empty intersection may later receive an obstructive/excavation annotation and a singleton may receive a constructive-sharpening annotation. These are observational and scheduling semantics only. The CRT conditions and exact mode-set intersection are the proof-bearing objects.
