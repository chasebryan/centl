The first end-to-end CBX run exposes the hidden first-depth distribution beneath the production W cover.

Source note in the repository

Status: finite implementation-validation census

Claim boundary: the statistics below are finite observations. The maximum 107 is not a universal bound, does not establish an adaptive K law, and does not prove Erdős–Straus.

Run

The validation used the default grade

\Gamma=(F,K_I,E_N,A_L)=(11,400,300,400)

with fixed Lane-I policy and sweep only.

cbx go --run e2e --step 5000 --sweep-only

Why this matters

The production matrix can legitimately show I/N/L near zero because W already marked the target. CBX demonstrates that the hidden lanes are extremely active when evaluated independently. The research object is now measurable:

\boxed{\text{the conditional distribution of }k_I^*(p)\text{ beneath W}.}

The next experiment is to track record-depth events inside R/fab-only and correlate them with spectrum, factor structure, signed-box size, defect/stabilizer signatures, first external NR prime, and López depth.

Erdős–Straus remains open. The observed Lane-I maximum 107 is a finite record, not a bound.
