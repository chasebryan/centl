Theorem

The local research state now contains enough exact cross-coordinate implications that manual propagation is itself becoming a source of error.

Source in the repository

Status: research implementation of the landed reduced dependency grammar

Date: 2026-08-16

Implementation: propagate_h169_dependency_state.py

Claim boundary: this tool propagates already-proved constraints inside the realized h169 pair-route survivor laboratory. It does not prove that any surviving formal tuple has an arithmetic realization, does not generalize the two routes to all h169 survivors, does not establish termination, and does not prove Erdős–Straus.

1. Purpose

The local research state now contains enough exact cross-coordinate implications that manual propagation is itself becoming a source of error.

The propagator turns the landed dependency grammar into an executable finite constraint system.

Given a partial state such as

route = B
k19_mode = BARE

it applies only the theorem rules already proved in-tree and returns the exact remaining formal domains. In this example it derives

tau19 = 8
k27_mode = Q
E_support = QR27.

The tool is deliberately a research grammar engine, not a new CBX cover lane and not a decomposition oracle.

2. Scope

The universe is the realized h169 pair-route simultaneous-survivor grammar used by H169-REDUCED-DEPENDENCY-GRAMMAR.md.

The proof-state fields are

tau19
tau31
tau4
tau9
k19_mode
k27_mode
k31_mode
k35_status
k47_mode   # Route B only; Route A uses NA internally

with base domains

tau19 in S19
tau31 in S31
tau4 in {0,1,2,3}
tau9 in {0,...,8}
k19_mode in {BARE,FULL_QR}
k27_mode in {Q,A,B,C,D,E,F}
k31_mode in {BARE,FULL_QR}
k35_status in {J_ONLY,S7_ONLY,BOTH}
k47_mode in {THIN,FULL_QR} on Route B.

Every enumerated formal state already means the relevant shifts are in their survivor/miss state. The tool must not be applied to an arbitrary integer without first establishing that route/survivor context.

3. Exact rules compiled in v1

The engine contains six named theorem predicates.

k19-bare-phase

Route A BARE -> tau19=2
Route B BARE -> tau19=8.

k27-phase8-q-selector

tau19=8
  -> 19|E
  -> on k27 miss: k27 mode Q
  -> E support QR27.

k31-bare-phase-seam

k31 BARE
  -> tau31 in {0,19,29}
  -> tau4 even.

route-b-k47-thin-even

Route-B k47 THIN -> tau4 even.

route-b-odd-full-full

Route B + tau4 odd
  -> D-J gcd2 seam
  -> k31 FULL_QR
  -> k47 FULL_QR.

k35-v3-ge2-j-only

tau9=4
  -> 9|F
  -> S7 impossible
  -> k35 J_ONLY.

These rules are not hypotheses generated by the software. They are executable forms of landed research theorems.

4. Finite-set semantics

The implementation uses a deliberately simple semantics:

  1. enumerate the finite naive formal grammar for the selected route;
  2. apply any user-supplied partial assignments;
  3. filter by every exact theorem predicate;
  4. project the surviving tuples back onto each field;
  5. derive parity, 2-adic seam, k35 valuation bucket, and support consequences from those projections.

This is equivalent to enforcing the current finite relational grammar to a fixed point. No search order can create a state that is not present in the theorem-defined relation.

A zero-size result is an exact contradiction inside this grammar scope.

A nonzero result means only “not excluded by the compiled theorems.” It does not assert existence of an integer realizing any remaining tuple.

5. Examples

Route-B BARE propagation

python3 research/erdos-straus/propagate_h169_dependency_state.py \
  --route B \
  --k19-mode BARE \
  --json

The projected state forces

tau19=8
k27_mode=Q

and reports the QR27 support consequence.

Exact contradiction

python3 research/erdos-straus/propagate_h169_dependency_state.py \
  --route B \
  --k19-mode BARE \
  --k27-mode A \
  --json

This returns an empty formal state set because BARE forces tau19=8 and that phase forces k27 mode Q.

Route-B odd seam

python3 research/erdos-straus/propagate_h169_dependency_state.py \
  --route B \
  --tau4 1 \
  --json

The output forces

k31_mode=FULL_QR
k47_mode=FULL_QR
gcd(D,J)=2.

JSON partial state

python3 research/erdos-straus/propagate_h169_dependency_state.py \
  --route A \
  --state-json '{"k31_mode":"BARE","tau9":[1,4,7]}' \
  --json

Scalar values mean exact assignments. JSON lists mean allowed domains.

6. Output classes

The JSON report separates:

  • input_formal_tuples: tuples satisfying only the supplied partial state;
  • surviving_formal_tuples: tuples remaining after the exact grammar;
  • theorem_trace: named rule filters and their ordered elimination counts;
  • domains: exact field projections of the remaining formal relation;
  • forced: singleton field projections;
  • derived: parity, support seam, k35 valuation bucket, and D-J gcd domain;
  • support_consequences: theorem-safe support statements available from the projected state;
  • contradiction: whether the formal relation is empty.

The elimination count attached to an individual rule is telemetry for the fixed rule order. Rules can overlap, so that count must not be interpreted as a unique causal decomposition of the final compression.

7. BEC / BREC annotation boundary

--annotate-bec adds a candidate directional annotation to theorem-trace events.

In v1 the compiled rules are restriction/collapse rules and are therefore natural candidates for

↓(⊖/⊕)

metadata.

The output explicitly labels these annotations as observational scheduling metadata only.

The engine never reads a BEC/BREC annotation when deciding whether a state survives. Removing all directional metadata leaves the mathematical result unchanged.

This implements the required separation:

exact theorem relation -> proof state
BEC/BREC direction      -> interpretation / scheduling metadata.

8. Self-tests

--self-test pins at least the following regressions:

  • empty partial state reproduces the landed grammar counts:

- Route A 105,600; - Route B 147,900;

  • Route-B BARE forces tau19=8 and k27=Q;
  • Route-B BARE plus k27=A is contradictory;
  • Route-B odd tau4 forces FULL_QR at k31 and k47 plus D-J gcd2;
  • Route-B THIN restricts tau4 to {0,2};
  • k31 BARE restricts tau31 to {0,19,29} and tau4 to {0,2};
  • tau9=4 forces J_ONLY;
  • Route-A BARE fixes tau19=2 but does not falsely collapse k27.

9. Why enumeration is acceptable here

The finite formal grammar is currently under one million naive tuples on Route B. Exhaustive symbolic filtering is therefore cheap, transparent, and much safer than introducing an optimizer or SAT encoding prematurely.

If the state grows substantially, the same named constraints can later be compiled into a CSP/SAT/BDD representation. That would be an implementation change, not a mathematical change.

10. Next engineering step

Once this research propagator is stable, CBX theorem-mining tools can call it before expensive factor work to answer:

what does the existing proof grammar already force on this partial research state?

Any scheduling use must remain advisory until separately integrated and tested. Cover semantics and W -> I -> N -> L remain unchanged.

11. Next mathematical step

The propagator also turns theorem gaps into visible unresolved domains.

The highest-value next mining targets are states where the engine leaves several k27 modes or Route-A k51 endpoint sectors alive despite strong upstream assignments. Those are precisely the places where another cross-coordinate theorem would create the largest state contraction.
