Exact fixed-shift theorem

The complete k=39 state problem is exactly conjugate to the k=35 C12 × C2 classification.

Canonical research note · Machine certificate

Status: exact computer-assisted finite-group classification. Erdős–Straus remains open.

The conjugacy

Modulo 39, use coordinates x = 14^ε · 28^a in C2 × C12. Hard shifted integers C=(p+39)/4 lie in the ε=0 subgroup. The Type-I target is (1,4), while -1=(1,6) and Type II is (1,c+6).

The automorphism (ε,a) → (ε,5a) fixes (1,6) and sends the k=35 Type-I target (1,8) to the k=39 target (1,4). It therefore carries the complete k=35 factorization-state system and miss table bijectively onto k=39.

Character split

The fixed-shift Jacobi law becomes (13/p)=(-1)^c. Both character branches occur in the exact miss table:

(13/p) = +1   122 miss states
(13/p) = -1   110 miss states

The minimum outside-subgroup representative distribution is again {0:92, 2:138, 4:2}. This is a statement about equivalent group states, not a bound on the number of prime factors of the original integer.
