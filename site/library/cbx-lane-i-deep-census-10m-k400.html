Exact result

The domain contains 20,513 Mordell-hard primes. All three exact Lane-I traversals agree on the complete p → k_I*(p) map:

\text{p-major}=\text{target-gated C-major}=\text{shift-major}.

All 20,513 / 20,513 are covered through K_I=400. The finite Lane-I residual set is empty.

Observed depth frontier

K_{min}^{obs}(10^7)=107.

The only productive shifts are:

3, 7, 11, 15, 19, 23, 27, 31, 35, 39, 43, 47, 51, 55, 59, 107.

First-hit depth quantiles are p50=7, p90=15, and p99=31. The unique finite record prime remains 8,803,369, which first hits at 107.

The one-prime gauntlet

After k=59, one target remains. It survives

63, 67, 71, 75, 79, 83, 87, 91, 95, 99, 103

before hitting at 107. Those eleven shifts are finite dead-with-factorization layers for this corpus, not universally redundant shifts.

Spectrum balance

First-hit totals are nearly balanced across the three spectra:

A=6,857,\qquad B=6,854,\qquad C=6,802.

Three orientations, one expensive work set

Each orientation performs exactly 45,553 signed-box factorizations. Shift-major also makes exactly the same number of active target/shift visits as p-major shift candidates.

Target-gated C-major nevertheless enumerates 7,142,900 compatible C candidates, a ratio of 156.804162× relative to the required factorizations.

Fedora timings

p-major      0.101051157 s
C-major      0.138304172 s
shift-major  0.101046738 s

The median wall ratios are 1.368655× for C-major and 0.999956× for shift-major relative to p-major. Shift-major is interpreted as practical parity, not a speed theorem.

What this changes

The computational bottleneck for C-major is now clear: generic compatible-C enumeration, not extra factorization. A genuinely faster generated cover needs a structural prefilter or direct generator for delta_k(C)=0.

The next engineering layer should be a measured hybrid planner that compares per-shift C-major generation cost, shift-major survivor cost and p-major recognition cost under explicit assumptions. It must report sensitivity rather than pretending the finite profile proves a universal scheduler.
