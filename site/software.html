CentL26 Universal Release Matrix (v26.10.0)

CentL26 is distributed as an offline standalone application across macOS, GNU/Linux, and Windows 11. All targets execute the exact same deterministic Rust core with 100% feature parity.

macOS Desktop (Apple Silicon & Intel)

Native AppKit & WebKit laboratory application with dynamic STEM animated visualizer and theorem studio.

# 1-Command Setup:
./install.sh
open build/centl26/macos/CentL26.app
macOS Manual

GNU/Linux (x86_64 / ARM64)

Standalone tarball distribution for Debian, Ubuntu, Fedora, RHEL, and Arch Linux systems.

curl -fsSLO https://raw.githubusercontent.com/chasebryan/centl/main/install.sh
sh install.sh
centl26
Linux Manual

Windows 11 (x86_64)

Complete standalone distribution archive with launcher script, native icon, and automated installer.

# PowerShell Automated Setup:
powershell -ExecutionPolicy Bypass -File scripts\install-windows.ps1
