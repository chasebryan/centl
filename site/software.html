Install CENTL

curl -fsSLO https://raw.githubusercontent.com/chasebryan/centl/oasis/install
sh install

CENTL v0.15.0 Al-Nur is the published Oasis release for GNU/Linux x86_64. The installer verifies the archive, then activates. See the installation guide.
