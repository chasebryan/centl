Hosting policy

FCF distinguishes an index from a mirror. This page may point to canonical release objects, but Mirrors / pub records whether the underlying bytes are actually preserved under FCF control.

Large binary artifacts should not be forced into the Pages Git repository. GitHub Releases or a dedicated FCF mirror store are the appropriate backing store, with this HTTPS site acting as the stable human-readable directory.
