Semantic publication

An operator can verify and export a redistribution-approved preserved CENTL-SCi model with scripts/model-origin-export.py. The export is content-addressed, includes provenance and SHA-256 receipts, and emits a CARAVAN catalog for the same exact model bytes. See the FCF Semantic Origin contract.

Hosting policy

FCF distinguishes an index from a provisioner. This page may point to canonical release objects, while The Bazaar records whether underlying bytes are actually preserved and publicly supplied under an FCF or CARAVAN distribution contract.

Large binary artifacts are not forced into the Pages Git repository. The static site remains the stable human-readable directory; large qualified artifacts belong in a dedicated FCF origin or other explicitly provisioned backing store.
