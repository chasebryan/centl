Free Computation Foundation

The Free Computation Foundation develops and preserves software intended to keep serious computation available for study, modification, verification, scientific work, and independent operation.

Its current public project is CENTL v0.14.0, an Oasis-qualified exact-first mathematics, physics, and scientific computation system for GNU/Linux x86_64. CENTL-SCi v0.0.2-Caramels provides the current local scientific interaction surface.

Principles

  • Users should be able to study, modify, rebuild, run, and share the software they depend on.
  • Scientific computation should expose uncertainty and unsupported work rather than manufacture confidence.
  • Critical build, verification, release, and recovery inputs should be preservable independently of upstream availability.
  • Availability must not redefine authority: mirrors and CARAVAN carriers may supply bytes, while authenticated metadata identifies which bytes are trusted.
  • Semantic tooling may interpret intent, but it must not silently become mathematical authority.
  • Project infrastructure should remain understandable, auditable, replaceable, and recoverable.

Infrastructure

This site is deliberately static and requires no JavaScript. GitHub Pages supplies the initial public HTTPS directory. The source remains ordinary HTML and CSS so it can move to FCF-controlled infrastructure later without a framework migration.

Large preservation and semantic artifacts live outside the Pages repository. The site points to the stable Oasis release, canonical source, publication contracts, and the FCF origins and CARAVAN resources listed in The Bazaar. It does not represent a link as preserved bytes.

Support

FCF is supported by more than money. Code, tests, mathematical review, documentation, preservation work, reproducible bug reports, and infrastructure all strengthen the project.

Participating in CARAVAN is itself a form of support. When qualified public enrollment opens, a volunteer carrier can contribute bounded storage, bandwidth, and availability to approved FCF material. Until then, testing carrier preparation, host policy, platform compatibility, privacy boundaries, and failure behavior is useful project work.

Financial sponsorship is available through GitHub Sponsors and X Money. Current methods and public sponsorship totals are listed on the Funding page.
