The foundation

The Free Computation Foundation develops and preserves software so that serious computation stays available for study, modification, verification, and independent use.

The current public project is CENTL v0.15.0 Al-Nur, an Oasis release for GNU/Linux x86_64. FCF Camp #1 is the current stay, where the newest software and designs are used. A camp does not replace Oasis.

Principles

  • Users should be able to study, modify, rebuild, run, and share the software they depend on.
  • Scientific computation should expose uncertainty instead of manufacturing confidence.
  • Availability is not authority: a mirror may supply bytes; authenticated evidence identifies which bytes are trusted.
  • A language model may interpret intent. It does not become mathematical authority.
  • This website is HTML and CSS. It does not run JavaScript.

The longer policy texts live in the documentation index. Research records live in the research library.
