Status: Wellspring Candidate. This page reports a potentially new structural lens on the Type A/B congruence system used in research on the Erdős-Straus conjecture. Novelty and priority remain under review. The Erdős-Straus conjecture remains open.

What the candidate contribution is

The Type A and Type B solution forms are not new. Miguel Angel López introduced and studied those structures and conjectured that every prime has a Type A or Type B solution. The FCF candidate contribution is the structure built on top of that framework: a minimal first-hit depth, exact layer cardinality, a proof that the depth is unbounded over primes, and a CRT-based shadow relation showing that many later congruence layers are mathematically redundant.

Define m(k)=4k-1 and the Type A/B trap set

T_k = {-d, -4d mod (4k-1) : d divides k}.

The Type A/B witness depth is

C_AB(p) = min { k >= 1 : p mod (4k-1) is in T_k }.

This is the minimum product d*n among López Type A/B witnesses. It is intentionally called C_AB, not a global Erdős-Straus complexity measure.

FCF searched the six classical difficult residue classes modulo 840: 1, 121, 169, 289, 361, 529. There were 20,513 selected primes through 10,000,000. Every one received a Type A/B witness by depth 2622.

Exact trap cardinality

If tau(k) denotes the number of divisors of k, the experiment produced and checked the exact formula

|T_k| = 2*tau(k) - 1 - [4 divides k]*tau(k/4).

The subtraction comes from one universal cross-collision and an additional family of collisions exactly when 4 divides k. For k=2622, tau(k)=16, so the layer contains exactly 31 distinct Type A/B trap residues.

No universal constant depth

For every fixed K, let L_K be the least common multiple of 840 and all 4k-1 with 1 <= k <= K. Dirichlet's theorem supplies infinitely many primes p = 1 mod L_K. Such primes lie in the hard class 1 mod 840 and reduce to 1 at every Type A/B modulus through level K. But 1 cannot equal any trap residue -d or -4d at those levels. Therefore C_AB(p) > K.

So if López's Type A/B coverage conjecture is true, its witnesses must still occur at unbounded depths. A finite universal cutoff cannot prove the conjecture.

Congruence shadowing

The most revealing experimental turn came from conditional hazard analysis. Several layers had exactly zero first hits even though a prime-conditioned model expected many. The missing variable was survival history.

An admissible trap class at layer k combines a hard residue h mod 840 with a trap residue t mod (4k-1). CRT turns that into one progression r mod L. At an earlier layer j, the progression occupies exactly the residue fibre congruent to r mod gcd(L,4j-1). If that entire fibre lies in T_j, the later class is already covered and is directly shadowed.

Example: k = 14 is mathematically redundant

For k=14, the modulus is 55. The relevant admissible trap residues reduce modulo 11 to 8, 7, 10. But layer 3 has modulus 11 and trap set {7,8,10}. Therefore every admissible hard-prime hit at layer 14 was already a hit at layer 3.

k=14  m=55  classes=9  shadowed=9  novel=0  sources=[3]

Consequently no selected hard prime can have C_AB(p)=14. The observed zero at layer 14 is an exact congruence consequence, not a statistical accident.

The remaining caveat: union shadowing

A directly fresh class is one that no single earlier layer covers completely. Several earlier layers might still cover different pieces whose union covers the whole class. The current shadow map has not yet solved that stronger union-shadow problem.

The particular class containing p=9658489 is known to contain at least one globally surviving point through layer 2621 because the independent minimality verifier checked the prime itself. That does not automatically establish union irredundancy for all 186 admissible classes at layer 2622.

Novelty status

The current novelty candidate is the package consisting of minimal Type A/B witness depth, certified frontier behavior, exact trap cardinality, unboundedness, and the CRT congruence-shadow hierarchy that exposes redundant Type A/B layers.

A targeted 2026 primary-literature search did not find this exact invariant and shadow structure. That is not a priority proof. FCF will keep the result at Wellspring Candidate status until a broader prior-art review, independent mathematical review, and stronger union-shadow analysis are complete.

What comes next

The immediate research target is the irredundant Type A/B sieve: classify completely redundant depths, compute union shadowing, identify infinite shadow families, study the growth of C_AB, and determine whether the remaining irredundant congruence structure can illuminate López's global Type A/B coverage conjecture.
