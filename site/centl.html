Overview

CENTL is an exact-first mathematics and physics system. Exact values stay exact when the admitted mathematics permits it. Requested approximations carry justified bounds. Unsupported work stays visible.

CENTL v0.15.0 is an Oasis release. This Oasis is named Al-Nur. The canonical tag is v0.15.0. See the Oasis release standard.

FCF Camp #1 is the current stay, on main and mirage. That is where the newest software and designs are used. A camp does not replace Oasis.

Install

curl -fsSLO https://raw.githubusercontent.com/chasebryan/centl/oasis/install
sh install
centl-sci

GNU/Linux x86_64 is the supported Oasis target. Offline archives and the release contract are in the installation guide.

centl '0.1 + 0.2'
centl-physics convert 100 cm m

The numerical rule

  • Integers, fractions, and decimal literals are exact values.
  • Exact results remain exact for as long as supported mathematics permits.
  • Approximations return justified enclosures, not unqualified guesses.
  • Dimension errors and unsupported work fail explicitly.
  • Every unqualified printed digit must be justified.

The full contract is NUMERICS.md. Language, physics, and the interpreter are documented from the documentation index.

Mathematicians can start at field onboarding. Physicists can start at physicist onboarding.
