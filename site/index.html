Free for science

The Free Computation Foundation publishes software that keeps serious computation exact when the mathematics permits it, and honest when it does not. CENTL is the current project. This site is static HTML and CSS. No JavaScript is required, and none is served.

Research library

Every public FCF research record is hosted on this site: Wellspring candidates, theorem notes, certificates, and the Erdős–Straus Type A/B program. Search suggestions appear as you type. Filters work in CSS. Nothing on this site requires a script.

Open the research library Read the Erdős–Straus program

Erdős-Straus Type A/B witness depth and congruence shadow structure. FCF has preserved a new Wellspring Candidate arising from CENTL exact-verification work. The research defines a minimal Type A/B witness-depth invariant, records an independently checked frontier through the six difficult residue classes below 10,000,000, proves an exact Type A/B trap-cardinality formula and unbounded depth over primes, and identifies a CRT shadow relation that makes many later congruence layers provably redundant. cbis.kernel is the ES+ letter engine: sweep from 0 plus R-homing (./centl es cbis). R is the residual where both 4p+1 and p+4 have only prime factors ≡ 1 (mod 4).
