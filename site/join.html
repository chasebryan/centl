🐪 Prepare this camel

Choose what this Linux machine should help preserve, accept the short host contract, and download one launcher made for those choices. When you execute it, the launcher verifies the signed FCF release, installs the current CENTL Oasis release, enrolls the machine, assigns its live Caravan number, and starts the outbound heartbeat.

No repository checkout or Tailscale membership is required. The launcher uses ordinary HTTPS by default; Tor is optional. This page does not run JavaScript. The matching download appears after you accept the contract.

Choose the FCF-approved provisions

What should this camel carry?

These choices filter authenticated FCF-approved cargo only. They never authorize arbitrary files, uploads, or software.

Short host contract

By joining, you choose to contribute bounded storage, bandwidth, and availability to authenticated FCF public-approved material. Your home files are never cargo. The carrier runs rootless, opens no public inbound port, accepts no arbitrary uploads, and publishes no hostname, username, IP address, or public node listing. You may leave with fcf-caravan-withdraw.

Default choice: source and releases over HTTPS. After download:

bash ~/Downloads/fcf-caravan-join-1.0.8-source-releases-https.sh

Each launcher downloads fcf-caravan-join-1.0.8, verifies FCF-CARAVAN-JOIN.pub, checks EXPECTED_HELPER_SHA256 for fcf-signify-x86_64-glibc, and runs signify -V -q before join-caravan --missions "$MISSIONS" --transport "$TRANSPORT".

Signed release assets

You may also fetch the official signed join release and run it yourself:

  • fcf-caravan-join-1.0.8.tar.gz
  • SHA256SUMS and SHA256SUMS.sig
  • FCF join public key
tar -xzf fcf-caravan-join-1.0.8.tar.gz
./fcf-caravan-join-1.0.8/join-caravan --missions source,releases --transport https

After execution, the welcome message reports everything installed, the provisions accepted, your live Caravan number, funding links, and other ways to help. Funding is optional: support FCF, preserve source and releases, test the carrier, improve documentation, review policy, or report bugs.
