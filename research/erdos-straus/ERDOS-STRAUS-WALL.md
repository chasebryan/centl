# Erdős-Straus — Wall

**Status: OPEN**

## Closed on this route

- Density-one Type A/B coverage of primes
- Finite DSC through k ≤ 1500
- Ancestry rigidity (13,17,21,29)
- C1, C2-coprime, **CN-coprime for all finite n**
- Lift-room, totient-ratio, and C2-thin reduction of shared-factor escape
- Admissible complementary `q=3` covers: **none** through `k ≤ 1500`

## Still required

1. Cap-free proof that an admissible `r` cannot complementary-cover at `q=3`
2. Universal DSC-P (all residual geometries)
3. López Type A/B for **every** prime
4. Composite `n`

## Honest floor

Coprime active cores of every finite size are reduced-realizable. Shared-factor escape is no longer an unstructured CRT problem: it is a 3-adic complementary-cover question, and unrestricted (non-admissible) complementary covers exist. That is progress. It is not Erdős-Straus.
