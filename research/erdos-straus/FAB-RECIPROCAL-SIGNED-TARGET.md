# Reciprocal fab lane collapses to the signed target -1

**Status:** exact theorem  
**Date:** 2026-08-15  
**Depends on:** `FAB-FIXED-K-SQUARE-DIVISOR.md`, `FAB-RECIPROCAL-DUALITY.md`  
**Claim boundary:** this is a reformulation of an exact sufficient certificate condition. It does not prove that a certificate exists for every prime.

## 1. Signed divisor set

Let

\[
n=\prod_r r^{e_r}
\]

with `gcd(n,m)=1`. Define the bounded signed divisor set

\[
\boxed{
\Sigma_m(n)
=
\left\{
\prod_r r^{z_r}\pmod m:
-e_r\le z_r\le e_r
\right\}.
}
\]

Every divisor

\[
D\mid n^2
\]

has exponents `0<=u_r<=2e_r`. Writing

\[
z_r=u_r-e_r
\]

gives

\[
\boxed{
D\equiv n\prod_r r^{z_r}\pmod m.
}
\]

Therefore, for any unit target `T mod m`,

\[
\boxed{
\exists D\mid n^2:\ D\equiv T\pmod m
\iff
Tn^{-1}\in\Sigma_m(n).
}
\]

The set `Sigma_m(n)` is closed under inversion because replacing every `z_r` by `-z_r` stays inside the same exponent box.

## 2. Forward lane

For

\[
X_m=\frac{p+m}{4},
\qquad
p\equiv1\pmod4,
\qquad
m\equiv3\pmod4,
\]

we have

\[
X_m\equiv p4^{-1}\pmod m.
\]

The square-divisor target is

\[
D\equiv-4^{-1}\pmod m.
\]

Hence

\[
D X_m^{-1}\equiv-p^{-1}\pmod m.
\]

By inversion symmetry this is equivalent to the already-known signed target `-p`:

\[
\boxed{
\text{forward at }m
\iff
-p\in\Sigma_m(X_m).
}
\]

## 3. Reciprocal lane

For

\[
Y_m=\frac{pm+1}{4},
\]

there is a stronger collapse:

\[
\boxed{
Y_m\equiv4^{-1}\pmod m,
}
\]

which is completely independent of `p`.

The same square-divisor target therefore gives

\[
(-4^{-1})Y_m^{-1}\equiv-1\pmod m.
\]

Thus:

### Theorem — reciprocal signed-target collapse

For every prime `p=1 mod4` and every `m=3 mod4` coprime to `p`, the reciprocal lane succeeds if and only if

\[
\boxed{
-1\in\Sigma_m\left(\frac{pm+1}{4}\right).
}
\]

The local target is now the single constant group element `-1`. The prime `p` affects only the factorization of the linear form; it does not occur in the residue target.

This is strictly cleaner than the forward lane, whose signed target is `-p`.

## 4. Coupling of the two linear forms

The forward and reciprocal bases are not unrelated. They satisfy

\[
\boxed{
mX_m-Y_m=\frac{m^2-1}{4}.}
\]

Consequently

\[
\boxed{
\gcd(X_m,Y_m)\mid\frac{m^2-1}{4}.
}
\]

For fixed `m`, all common prime support of the two lane bases is therefore confined to a constant integer independent of `p`.

This means a hypothetical simultaneous failure at fixed `m` consists of two nearly disjoint factorizations:

- `X_m` whose bounded signed divisor set avoids `-p`;
- `Y_m` whose bounded signed divisor set avoids `-1`;
- with shared prime support possible only through divisors of `(m^2-1)/4`.

That is a sharper structural obstruction than treating the two lanes as unrelated searches.

## 5. First examples

### m=3

The unit group modulo `3` has only `{1,-1}`. Since

\[
X_3=\frac{p+3}{4},
\qquad
Y_3=\frac{3p+1}{4},
\]

and a hard prime has `p=1 mod3`, both lanes have signed target `-1`.

Failure of either lane is therefore equivalent to every prime factor of its base being `1 mod3`.

Thus simultaneous failure at `m=3` forces the familiar pair

\[
\frac{p+3}{4},
\qquad
\frac{3p+1}{4}=3\frac{p+3}{4}-2
\]

to lie entirely in the multiplicative semigroup generated by primes `1 mod3`.

### General m

For larger `m`, `Sigma_m(n)` is a finite-state multiplicative object. The reciprocal formulation shows that its forbidden element is always `-1`, while the coupling identity confines overlap between the forward and reciprocal prime supports to a fixed constant.

This suggests a new proof program: classify the finite signed-divisor failure states for small `m=3 mod4`, then prove that the coupled linear forms cannot remain in compatible failure states for every member of a finite or controlled expanding menu of `m`.
