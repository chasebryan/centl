# CBAP letters

This folder is for **LETTER** files only. CBAP never writes GOOD or GREAT.

Each letter is `L-<32 hex chars>.md`. The name is the first 128 bits of
SHA-256 of the same `ES-LETTER-v1` key used by bb.kernel. The start
factor, the clock, and the host are not in the key.

A letter is not a counterexample by itself. Erdős–Straus remains open
unless a letter named `universal_strike` points at a complete deposited
proof.
