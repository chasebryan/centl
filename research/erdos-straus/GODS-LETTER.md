# God's Letter

**God's Letter is the UI nickname for an unresolved incomplete residual.**

It is not a solved object. It is not a counterexample. It is not a proof.

$$
G(p)=\text{Mordell-hard prime with no verified witness after the currently declared engine menu, complete region not yet exhausted}
$$

A verified identity \(4/p=1/x+1/y+1/z\) is a **Letter**, **Remnant**, or **Escape**. Never a God's Letter. \(p=2521\) is a solved origin letter, not a God's Letter.

Hardness measures tell us where to look. Certificates tell us what is true. Dual-descent survival is a **bounded hardness proxy**, not a proof of nonexistence.

---

## Ladder

| Name | What it is |
|---|---|
| **Letter** | Notable solved hard-prime decomposition (Mordell-hard, exact witness, depth gate). |
| **Remnant** | Solved prime carrying an independently measured deep-hardness signature. Discovery engine and hardness engine may differ. |
| **Escape** | Solved candidate outside Letter admission geometry. |
| **God's Letter** | Unresolved incomplete residual. Menu miss. Not a disproof. |
| **DIS ticket** | Exhaustive certified counterexample: complete finite \(x\)-region empty. |
| **Victory certificate** | Universal covering of the six Mordell classes \(\{1,121,169,289,361,529\}\pmod{840}\). None exists yet. |

**interesting solved → unusually hard solved → unresolved → certified impossible**

No category pretends to be the next one.

---

## Hunt

The God's Letter filter runs the full engine stack (CC, two-target corridor, two-target \(k\), divisor-complete for \(n\le 10^4\), bb verify) over every prime in the window. It does not skip non-Mordell primes: those are exactly the primes CC can clear.

The numerical frontier of this observatory is **not** a verification record. Salez (2014) already reported computational verification through \(10^{17}\). CentL's contribution is an inspectable machine that separates theorem coverage, constructive witnesses, hardness proxies, incomplete regions, and genuine finite nonexistence certificates.
