# God's Letter Vault

God's Letters are **unsolved Mordell-hard primes** after the full engine menu (CC theorems + two-target corridor + BB).

A verified identity \(4/p = 1/x+1/y+1/z\) is a **Letter**, **Remnant**, or **Escape** — never a God's Letter.

Solved Mordell census files that were previously misfiled here live in `archive/solved-mordell-census/`.

| File | Description |
|---|---|
| `GL-<p>.json` / `GL-<p>.md` | Unsolved Mordell-hard prime (search-horizon miss, not a counterexample proof) |
| `current.json` | Latest unsolved God's Letter, if any |
| `index.json` | Manifest of active unsolved letters |
| `archive/solved-mordell-census/` | Prior solved identities, kept for record |

`strike` remains false until a universal ES construction is deposited.
